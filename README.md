# حجوزاتي — صفحة المشاركة الرسمية

رابط الجمهور الثابت: **https://abukamil.github.io/hajozati-landing/**

مصدر الصفحة المعتمد هو فرع `main` في هذا المستودع. تُنشر التغييرات المدموجة فيه تلقائيًا عبر GitHub Pages من المجلد `/`. لا تُنشر تعديلات منفصلة مباشرة على `gh-pages`؛ محتوى الفرع المنشور سابقًا، بما فيه زر واتساب العائم، محفوظ في `main`.

تتكون الصفحة من `index.html` و`app-icon.png` و`social-card.png`. أبقِ روابط الملفات النسبية حتى تعمل داخل `/hajozati-landing/`، وأبقِ canonical وOpen Graph على رابط المشاركة الثابت نفسه.

أزرار إنشاء الحساب والدخول والخصوصية والشروط تستخدم التطبيق الحي على `https://hajozati.onrender.com`. GitHub Pages يستضيف الصفحة التعريفية؛ خدمات الحجز وقاعدة البيانات تعمل على Render. تحديث صفحة المشاركة لا يتطلب تغيير رابط الجمهور، ونشر الخدمة الخلفية يتم من مستودع `hajozati-pro-production` بشكل مستقل.

قبل النشر، راجع تغييرات الصفحة وتحقق من روابط إنشاء المساحة ولوحة المالك وواتساب والصور. بعد الدمج، تحقق من نجاح GitHub Pages ومن فتح الرابط العام. لا تضع مفاتيح أو بيانات خاصة داخل ملفات الموقع.
